# 琴阶 PianoPath

> 每周 4 小时的钢琴学习工作台：每日一课、逐分钟练习、国内教学资源、学习路径、打卡记录和轻量音乐游戏。

## 产品概览

- **学习路径**：12 周、48 次、每次 60 分钟；每课拆成 7 段逐分钟任务。
- **长期路线**：0–3 个月、3–12 个月、1–3 年、3–6 年、6–8 年。
- **国内优先**：默认只显示 B 站公开课与官方教材/考纲；YouTube 资源仅在“全部来源”中出现。
- **交互练习**：双八度节奏钢琴、10 音跟弹、音名找键小游戏、逐段计时、音频节拍、暂停、完成打卡。
- **学习反馈**：连续天数、XP、课次完成率、热力图、六周柱状图、历史笔记。
- **个性化**：按每周总时长和练习天数自动重排单次任务。
- **PWA**：可安装到桌面、离线打开，带 Service Worker 缓存。
- **主题**：亮色与深色模式。

### 1.22 电子琴节拍器

- 自由弹电子琴新增 40–208 BPM 节拍器，每次以 4 BPM 调整并记住上次速度。
- 使用 Web Audio 提前调度节拍，提供稳定的音频重拍/弱拍与四拍视觉提示。
- 切到后台、退出自由弹或关闭电子琴时自动停止节拍，避免后台持续发声。
- 压缩手机横屏控制区，优先保留 112 px 高的可触控琴键；桌面与手机回归已覆盖。

### 1.21 隐私与条款

- 新增可直接访问的隐私政策与服务条款页面，说明本机数据、账户同步、保存期限、删除方式与第三方资源边界。
- 注册账户必须勾选同意当前版本条款，服务端强制校验版本并记录同意时间。
- 账户面板新增隐私与条款入口；单文件离线版使用内置可访问弹窗，不依赖联网打开。
- 新增法律页面、注册同意、服务端记录、离线缓存和桌面/手机回归测试。

### 1.20 电子琴横屏

- 在手机或平板点进“自由弹”时自动请求横向；电子琴页也保留“横屏弹奏 / 退出横屏”切换。
- 支持时优先请求全屏并锁定系统横屏。
- Android 等支持方向锁定的浏览器会直接横屏；不支持方向锁定的 iPhone 会自动切换为横向旋转布局。
- 再次点击“退出横屏”、返回曲目或关闭电子琴时，会恢复方向锁定与页面状态。

### 1.19 曲库扩充

- 节奏钢琴由 4 首扩充到 8 首公共领域短曲，新增雅克兄弟、伦敦桥、老麦克唐纳与友谊地久天长。
- 曲目页增加“全部 / 入门 / 进阶”筛选，保留每首曲目的最佳准确率。
- 新增曲目筛选、数量与可访问状态的桌面和手机回归测试。

### 1.18 自由弹练习记录

- 自由弹会实时显示触键数和不同音数量，退出后自动写入最近练习。
- 有效自由弹记录会计入每日短练任务和累计练习分钟，不会误算为主课完成。
- 自由弹记录会保存到本地进度与备份中，并随账户同步。
- 节奏曲目卡会显示该曲历史最佳准确率；练习历史会区分主课、短练、跟弹、音乐游戏、曲目训练与自由练习。
- 自由弹同时保存真实秒数与累计分钟，短时练习不会被虚增为整分钟。
- 桌面、手机与横屏自由弹路径均增加了持久化回归覆盖。

### 1.17 自由弹电子琴

- 节奏曲目页新增“自由弹”，可在不开始曲目的情况下直接演奏。
- 自由弹保留双八度 26 键触屏布局，并通过音域切换覆盖 `C1–D7`；手机无需压缩成不可点击的 88 键。
- 电脑继续使用双排键盘映射，切换音域后字母键位置不变，可直接移调演奏。
- 自由弹会显示当前音名与最近演奏音，支持触屏、电脑键盘、全屏与横屏使用。

### 1.16 统一危险操作确认

- “清除全部本地数据”和“清除练习记录”使用同一套应用内确认弹窗，不再调用浏览器原生确认框。
- 清除练习记录会同时重置课程完成、掌握成绩、复习队列和进行中的练习，学习计划会保留。
- 确认流程支持焦点锁定、Esc/取消安全退出和焦点恢复。
- 桌面与手机端均有持久化回归覆盖。

### 1.15 双排键盘与内容审计

- 节奏钢琴和 10 音跟弹使用统一、常见的双排按键映射；手机与平板直接触控。
- 低音区白键 `Z X C V B N M`、黑键 `S D G H J`；高音区白键 `Q W E R T Y U I O`、黑键 `2 3 5 6 7`。
- 48 节主课都必须包含国内或官方来源，且禁止混入 YouTube；运行时禁止 Web MIDI 接入。
- 离线测试使用独立临时目录，结束后自动停止服务并清理数据。

### 1.14 账户数据控制

- 账户弹窗可删除账户与云端进度，并在应用内二次确认。
- 删除后撤销所有会话、级联清除服务器进度；本机练习记录保留。
- 移动端账户入口直达计划设置，删除与同步流程共享同一套弹窗焦点管理。

### 1.13 accessibility

- Modal focus entry, focus trap, Escape close and focus restoration.
- Background shell inert while dialogs are open.
- Visible keyboard focus and larger touch targets.
- Selection semantics and regression tests for onboarding.

### 1.12 节奏钢琴

- 内置双八度虚拟电子琴，四首公共领域短曲各有独立节拍与落点。
- 手机、平板可横屏直接弹奏；电脑可直接使用屏幕标注的双排字母键演奏。
- 节奏钢琴双排映射：低音白键 `Z X C V B N M`、黑键 `S D G H J`；高音白键 `Q W E R T Y U I O`、黑键 `2 3 5 6 7`。
- 10 音跟弹使用同一套低音区映射：白键 `Z X C V B N M`，黑键 `S D G H J`。
- 支持触控、键盘、暂停、全屏、准确率、连击、XP 和练习记录。
- 曲谱仅链接公共领域或官方来源，不内置受版权保护的曲谱。

### 1.11 自适应复习

- 未通过掌握检查、低评分练习或写了具体卡点的练习会自动加入复习队列。
- 每项复习按 1 / 3 / 7 / 14 / 30 天间隔推进；复习表现会决定下一次到期时间。
- 首页显示到期复习数量，学习记录页展示复习阶段并可直接开始 10 分钟定向复习。
- 复习数据会随账户同步，并包含在本地备份导入中。

### 1.10 跟弹练习

- 课程内和首页都可进入 10 音跟弹练习，提供示范播放、目标音高亮和即时对错反馈。
- 支持鼠标/触屏点击与电脑键盘双排映射，不依赖外部设备。
- 按准确率结算 1–3 星与 5/10/15 XP，保存最佳准确率、最佳连对和练习历史。
- 跟弹成绩会进入每日目标、XP、四项能力报告与技术练习统计。
- 手机、平板和电脑都可直接使用触屏或键盘演奏。

### 1.9 掌握门槛与能力报告

- 每节课程的三题掌握检查会写入本地状态，并在完成页显示最好成绩。
- 普通课程至少达到 2/3 才计入完成并解锁下一课；未通过只保存为练习记录，不发课次 XP。
- 快练、曲目训练与弱点复习不经过该门槛。
- 学习记录新增读谱、技术、曲目、听觉四项能力与最弱项下一步建议。
- 首页收敛为单一路径：主课、短练、音乐游戏，减少并列入口。
- 使用本机中文字体栈，并在 Windows 上优先 Microsoft YaHei UI。

### 1.8 掌握检查

- 每节课程可打开三题掌握检查，覆盖动作、练习方法和具体技术。
- 检查结果会保存到本地状态，并显示在完成页。


### 1.7 曲目库

- 10 首 0–8 级曲目，覆盖入门、初级、中级与高级。
- 支持按难度筛选、按曲名或作曲家搜索。
- 每首曲目有五个训练阶段：分段认谱、分手慢练、慢速合手、流畅连接、完整演奏。
- 曲目训练为 25 分钟独立会话；完成一次推进一个阶段并获得 15 XP。
- 曲谱只链接公共领域或官方来源，不在项目内托管受版权保护的曲谱。

### 1.6 弱点复习

- 低评分或写下具体问题的练习会进入“今天该复习什么”。
- 复习会话为 10 分钟：定位问题、慢速重练、接回前后、记录新状态。
- 复习记录独立保存，不会伪造成整课完成。

### 1.5 定位与短练

- 五题定位测评，根据结果建议从第 1 / 3 / 5 / 7 / 9 周开始。
- 5 分钟快练：1 分钟热身、2 分钟技术、1 分钟视奏、1 分钟复盘。
- 快练记录计入练习历史与每日任务，不标记整课完成，避免课程进度失真。
- 静态在线体验版明确提示“本机保存”，不再展示不可用的登录表单。

### 1.4 账户与跨设备同步

- 可选账户：注册/登录/同步/退出/删除，游客模式无需账户；删除账户会清除云端进度并撤销会话。
- PBKDF2 密码哈希、HttpOnly SameSite Cookie、会话过期与登录限流。
- SQLite 服务端进度存储，支持版本冲突检测与手动/自动同步。
- 离线优先：本地先保存，恢复网络后补传；账户进度按版本合并。
- 安全边界：数据库不作为静态文件暴露，API 拒绝跨源写请求。

### 1.3 学习闭环

- 首次进入提供三步目标设置，创建后直接进入第一课。
- 课程按顺序解锁；完成一课自动进入下一课，不再跳回内容列表。
- 支持中途退出与刷新恢复上次步骤、剩余时间。
- 进度体系：XP、等级、每日三项任务。
- 小游戏升级为“看音名找键”与“听声音辨音”双模式，支持重听、连击与最佳成绩。
- 练习页增加可选节拍器（60/72/84/96 BPM）。
- 计划可重新选择目标、恢复默认或清除全部本地数据。

### 1.2 首页重构

- 单一“开始今日练习”主行动，减少并列入口。
- 首页直接显示本周四次练习与 12 周阶段轨迹。
- 新增音名找键小游戏，带连击、得分和最佳成绩。
- 字体改用本机常用中文字体优先，不加载远程字体。
- 移除来源筛选门槛说明、核验日期和无关资料标签。


## 测试

```bash
npm run check

```

前端 E2E 需要 Playwright 与 Chromium；本项目在当前工作区使用内置 Playwright 与 Edge。`test:offline` 默认启动隔离的本地服务验证当前构建；设置 `PIANOPATH_OFFLINE_REMOTE=1` 时才检查线上 Service Worker 缓存。

## 快速开始

### 本地静态版

```bash
python -m http.server 8787
```

浏览器访问 `http://127.0.0.1:8787`。

Windows 双击 `启动PianoPath.cmd` 也会启动后端模式。

### 后端模式

```bash
python server.py
```

服务器默认监听 `http://127.0.0.1:8787`，数据写入 `data/state.json`。**无需安装第三方依赖。**

### 直接离线

`琴阶PianoPath.html` 为单文件版本，双击即可使用；进度保存在浏览器 `localStorage`。

修改源码后重新生成：

```bash
python tools/build-standalone.py
```

本机字体优先使用 `Microsoft YaHei UI`，其次 `PingFang SC`；不加载远程字体。

跟弹练习与节奏钢琴不依赖外部设备；手机、平板和电脑均可直接操作。

## 个性化 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 服务状态 |
| GET | `/api/plan/default` | 默认计划 |
| POST | `/api/plan` | 根据每周时长/天数/阶段/风格生成计划 |
| GET / POST | `/api/state` | 读取/保存学习状态 |
| GET | `/api/curriculum` | 完整课程与资源数据 |
| POST | `/api/auth/register` | 注册并建立会话 |
| POST | `/api/auth/login` | 登录并建立会话 |
| GET | `/api/auth/me` | 当前账户状态 |
| POST | `/api/auth/logout` | 退出并清除会话 |
| POST | `/api/auth/delete` | 删除账户并级联清除云端进度 |
| GET / POST | `/api/sync` | 跨设备读取/写入进度，带 revision 冲突检测 |

示例：

```bash
curl -X POST http://127.0.0.1:8787/api/plan \
  -H "Content-Type: application/json" \
  -d '{"daysPerWeek":4,"sessionMinutes":60,"level":"zero","style":"classical","goal":"半年内完整弹一首小奏鸣曲"}'
```

## 资源策略

默认资源只包含国内可访问或官方来源。48 节课的主路径由 `tests/content-audit.js` 强制审计：每课必须有国内或官方来源，且不得混入 YouTube。

## 部署

### GitHub Pages

上传至公共仓库后：

1. 打开仓库 **Settings → Pages**。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 `main` / root。
4. 保存后访问 `https://<username>.github.io/<repo>/`。

GitHub Pages 无后端，应用会使用浏览器本地存储；前端功能完整可用。

### 任意静态托管

将以下文件上传到网站根目录即可：`index.html`、`styles.css`、`app.js`、`data.js`、`sw.js`、`manifest.webmanifest`、`assets/`。
