## 产品概览

- **学习路径**：12 周、48 次、每次 60 分钟；每课拆成 7 段逐分钟任务。
- **长期路线**：0–3 个月、3–12 个月、1–3 年、3–6 年、6–8 年。
- **国内优先**：默认只显示 B 站公开课与官方教材/考纲；YouTube 资源仅在“全部来源”中出现。
- **交互练习**：双八度节奏钢琴、10 音跟弹、音名找键小游戏、逐段计时、音频节拍、暂停、完成打卡。
- **录音复盘**：课内主动录音、60 秒上限、本机声音体检、回放/下载/删除；音频只进 IndexedDB，不上传服务器。
- **学习反馈**：连续天数、XP、课次完成率、热力图、六周柱状图、历史笔记。
- **个性化**：按每周总时长和练习天数自动重排单次任务。
- **PWA**：可安装到桌面、离线打开，带 Service Worker 缓存。
- **主题**：亮色与深色模式。

### 1.41.8 深色模式完整适配

- 首页游戏区、每日目标、曲目卡、能力卡和统计卡统一使用深色表面。
- 深色模式下正文、辅助文字与描边同步适配，不再出现浅字白底。
- 恢复深色模式时主题按钮标签和 `aria-pressed` 从首屏起保持一致。
- 桌面与手机回归检查深色表面、按钮状态和横向溢出。

### 1.41.7 深色模式无障碍

- 恢复深色模式时，主题按钮一开始就显示正确的“切换浅色模式”标签和按下状态。
- 桌面与手机回归同时检查主题按钮的标签和 `aria-pressed`。

### 1.41.5 移动端对比度与可读性

- 手机和平板上的筛选、来源信息、曲目说明、教材说明和历史辅助文字提升到 10–11px，并保持 44px 触控高度。
- 学习路径周任务、曲目作曲家与状态、能力卡和学习统计的次要文字提高对比度，避免“字变大了但仍看不清”。
- 教学库较长的来源资质、课程说明与教材备注改为自然换行，320px 屏幕不再截断。
- “查看”来源、教材链接与搜索框补齐手机触控尺寸。
- 首次引导打开时先聚焦标题并关联说明，键盘和屏幕阅读器不再先落到关闭按钮。
- 320、390、768 和桌面尺寸完成主要页面布局与横向溢出检查，并把触控尺寸、字号、对比度和引导焦点写入回归测试。

### 1.40.2 快速离线与后台音色缓存

- 核心页面先缓存并快速激活；150 个钢琴采样在激活后分批后台补齐，不再阻塞首次离线可用。
- 状态区会真实显示“正在准备离线”“离线可用 · 音色 N / 150”或缓存失败，不再固定宣称已完成。
- 自动化测试分别验证核心激活耗时、后台缓存完成、断网重新打开和采样实际读取。
- 修复离线测试中异步轮询可能提前通过的缺陷。

### 1.40.1 离线安装修复

- 修复首次安装时 173 个资源一次性 `cache.addAll()` 导致 Service Worker 长时间卡在 `installing` 的问题。
- 先缓存核心应用壳，再分批缓存钢琴采样；每个资源最多重试三次。
- 核心壳缺失时安装明确失败，避免显示“离线可用”但实际上没有完成缓存。
- 回归测试现在同时检查版本一致性、缓存条目数、Service Worker 激活状态和断网重开。

### 1.40 电子琴与曲库

- 首页把自由弹电子琴升为整行主入口，手机和平板进入后可横屏演奏。
- 白键固定为一条连续下层：`Z X C V B N M , . / N1–N6`；黑键 `A S · F G H · K L · ; ' Enter`。D、J 留空，小键盘 7–9 不参与黑键。
- 屏幕琴键继续按真实钢琴几何绘制；黑键的十个邻里关系、物理键码、移调和节奏命中均有桌面/手机回归。
- 键位标签改为高对比不透明胶囊，手机竖屏与横屏都保持可读且不截断。
- 曲库扩到 12 首：8 首公共领域短曲和 4 首标注为非官方简化旋律的流行练习片段；支持流行筛选、时长显示和每首两轮。

### 1.39 错题进入复习队列

- 掌握检查未通过后，复习队列会保存这次的错题焦点和对应能力，而不只保存“未通过”状态。
- 复习卡片直接显示要补的具体动作；进入 10 分钟复习后，第一段围绕这个焦点做慢速自检。
- 首页错题卡、复习卡和复习会话使用同一份错题数据，避免三处显示不一致。
- 桌面和手机回归覆盖复习焦点持久化、复习卡文案和复习会话第一段。

### 1.38 环节化掌握检查

- 掌握检查会读取当前练习环节，分别考入场准备、定向扫谱、技术动作、曲目拆段、视奏连续性、听觉回应和反馈复盘。
- 每次打开检查都会显示当前环节与步骤名，避免把“技术题”错配到“视奏”或“复盘”。
- 曲目、读谱和听觉等弱项会以对应能力标签进入掌握档案，不再把所有错误都混成同一种技术问题。
- 桌面和手机回归覆盖环节切换、题目匹配、错题补练和晋级门槛。

### 1.37 首页错题召回

- 未通过掌握检查后，首页会保留一条“上次卡在这里”，直接显示最该补的纠正点。
- 点击后回到对应课程的掌握检查，不需要自己翻记录、找课次。
- 补题通过后首页提醒自动消失；否则继续保留，避免弱项被历史列表淹没。
- 桌面和手机回归覆盖提醒出现、跳转、补题通过和自动清除。

### 1.36 错题补救闭环

- 掌握检查答错后，反馈会直接给出一句可执行的纠正点，而不是只显示正确答案。
- 未通过时列出这次真正答错的知识点，并提供“只重练错题”；补题后仍按 2 / 3 门槛重新判定。
- 错题对应的能力标签会写入掌握档案；之后的读谱、技术、曲目和听觉画像会把这些弱项计入，避免分数只涨不降。
- 错题焦点、解释和最近一次结果进入本地学习记录，并随账户同步；换设备后仍能恢复。
- 桌面与手机回归覆盖错误反馈、错题清单、只重练错题、状态持久化和后续晋级门槛。

### 1.35 五层力度与本周复盘

- 电子琴升级为 Salamander Grand Piano V3 的 5 个真实力度层（vel 3 / 7 / 11 / 13 / 16），轻触与重击会使用不同的原始击弦样本，不再只是把同一个音量调大。
- 保留 A0–C8 的 30 个跨音区采样；共 150 个本地 MP3，按音区和力度按需解码；解码缓存上限 150 MB，避免手机长时间弹奏时持续占内存。
- 音色链路加入轻量演奏厅混响、低频琴体补偿、高频收敛、次声过滤和更宽松的动态压缩；手机扬声器下更清楚，和弦也不容易被压扁。
- 触屏支持按压力/落键深度模拟力度；电脑键盘使用稳定的中等力度；合成兜底同样响应力度。
- “记录”页新增本周复盘：本周/上周分钟对比、出勤天数、连续学习、薄弱能力对应的下一步行动。
- 音频回归检查 150/150 本地文件、30 个音区、5 个力度层、A0–C8 实际播放、混响空间与解码缓存上限。

### 1.34 带任务的录音复盘

- 课内新增“录音复盘”：点击后才请求麦克风，最长 60 秒；停止后可立即回放、下载或重录。
- 录音面板会根据主课、快练、曲目训练、阶段训练或复习，显示“这一条录什么”；任务说明随录音元数据保存，并在历史回放中恢复。
- 录音结束后在本地做“声音体检”：显示长度、音量、有效有声占比，并针对过轻、削波、静音或断续给出下一条练习建议。分析在本机完成，不上传音频，也不用于模型训练。
- 重录会自动保留上一条的体检摘要，比较两遍的音量、有效有声占比和削波/静音状态，给出“更稳 / 又偏了 / 一致 / 更连贯”的复盘提示；旧音频会被替换释放。
- 录音 Blob 只保存在本机 IndexedDB；学习历史只记录 `id`、时长、格式、来源和本机随机标识，不包含音频。记录信息可随进度同步，因此其他设备会显示“原设备录音”而不能播放该音频。
- 完成练习后可以在“记录”页回放或删除对应录音，删除音频不会删除文字复盘和练习记录。
- 拒绝麦克风权限不会中断练习；单文件版或非安全环境会明确说明录音不可用，钢琴和课程不受影响。
- 隐私政策、服务条款、CSP 媒体源和服务器麦克风策略同步更新，并增加录音专项回归。

### 1.30 录音棚级三角钢琴音色

- 虚拟钢琴换成 Salamander Grand Piano V3（Yamaha C5）30 个跨音区采样，覆盖 A0–C8；音色低频更厚、击弦更清晰、尾音更自然。
- 保留真实采样的击弦与衰减轮廓，移除原先过重的压缩和过早淡出；多个音符可以自然叠响。
- 30 个采样全部本地缓存并进入 PWA 离线包；解码失败时仍自动回退到多层合成器。
- 音频回归会检查采样源、音域、力度层、30/30 解码和真实首音播放。
- 采样来源、作者与 CC BY 3.0 许可见 `assets/audio/piano/README.md`。

### 1.27 中断续练与专注入口

- 首页主按钮会识别未保存的练习：刷新或退出后可直接从原练习、原段落继续。
- 曲目训练、阶段训练与 5 分钟快练会完整保存当前会话，不再只记录主课进度。
- 回到首页会清楚显示“继续 · 上次停在第 N 段”，避免初学者误以为进度丢失。
- 中断恢复保留做题、计时和完成记录所需的上下文，不把一次练习拆成未知状态。

### 1.26.1 引导式找键

- 教程改为真正的顺序引导：必须先找到 C3（`Z`）、C#3（`X`）、D3（`C`）。
- 下一个目标键会持续高亮；按错键仍有声音，但不会推进进度，并会提示正确的下一个键。
- 增加桌面与手机的按错恢复、目标高亮和顺序完成回归，避免“随便按三键就算完成”。

### 1.26 可试弹键位教程

- 键位教程从静态说明升级为可试弹键盘：电脑键盘、鼠标与手机触屏都能逐键试听。
- 使用物理键码识别按键，中文输入法、大小写与部分键盘布局不会干扰演奏。
- 增加 `Z → X → C` 三步试弹进度与完成反馈，教程内试听不计入正式练习次数。
- 教程保持两排布局，手机窄屏压缩单键宽度而不是把琴键折成四排。

### 1.25 两排键位教程与长期阶段训练

- 电脑键盘改为两排连续半音映射：下排 `Z–↵` 为 C3–C4，上排 `Q–\\` 为 C#4–D5；不再使用四组分散按键。
- 首次进入自由弹会打开独立键位教程，逐键显示电脑键、音名及黑白键；自由弹与节奏曲目内均可随时重新打开。
- 教程、节奏钢琴和自由弹使用同一套键位数据；桌面端与手机端均保持两排布局，不自动折成四排。
- 五年长期路线中的每个阶段可直接开始 60 分钟阶段训练，完成后保存到历史并回到学习路径。

### 1.24 提醒与系统日历

- 计划设置新增练习开始时间，首页与本周路线会同时显示星期、日期和具体时间。
- 一键生成未来 12 周的 `.ics` 日历文件，可在 iOS、Android、Google Calendar、Outlook 等系统日历中导入。
- 日历事件包含每周选定的练习日、开始时间、单次时长与课程名称，并能直接用于系统提醒。
- 练习时间随计划、备份和账户同步保存；缺失旧字段时自动补为 20:00。

### 1.23 练习日排期

- 计划设置新增“哪几天练琴”，7 个日期都可直接点选，选择数量与每周练习天数同步。
- 首页、本周路线和今日主课显示真实星期与日期；顺序按接下来发生的练习日排列。
- 练习日随计划、备份和账户同步保存；旧计划与旧备份缺少日期时自动补成合理默认值。
- 手机端 7 天选择器保持约 45×48 px 的触控尺寸，无横向溢出。

### 1.22 电子琴节拍器

- 切到后台、退出自由弹或关闭电子琴时自动停止节拍，避免后台持续发声。
- 压缩手机横屏控制区，优先保留 112 px 高的可触控琴键；桌面与手机回归已覆盖。

### 1.21 隐私与条款

- 新增可直接访问的隐私政策与服务条款页面，说明本机数据、账户同步、保存期限、删除方式与第三方资源边界。
- 注册账户必须勾选同意当前版本条款，服务端强制校验版本并记录同意时间。

### 1.20 电子琴横屏

- 在手机或平板点进“自由弹”时自动请求横向；电子琴页也保留“横屏弹奏 / 退出横屏”切换。

- 再次点击“退出横屏”、返回曲目或关闭电子琴时，会恢复方向锁定与页面状态。

### 1.17 自由弹电子琴

- 节奏曲目页新增“自由弹”，可在不开始曲目的情况下直接演奏。
- 自由弹保留双八度 26 键触屏布局，并通过音域切换覆盖 `C1–D7`；手机无需压缩成不可点击的 88 键。
- 电脑继续使用双排键盘映射，切换音域后字母键位置不变，可直接移调演奏。
- 自由弹会显示当前音名与最近演奏音，支持触屏、电脑键盘、全屏与横屏使用。

### 1.16 统一危险操作确认

- “清除全部本地数据”和“清除练习记录”使用同一套应用内确认弹窗，不再调用浏览器原生确认框。
- 清除练习记录会同时重置课程完成、掌握成绩、复习队列和进行中的练习，学习计划会保留。
- 确认流程支持焦点锁定、Esc/取消安全退出和焦点恢复。
- 桌面与手机端均有持久化回归覆盖。

### 1.15 双排键盘与内容审计

- 节奏钢琴和 10 音跟弹支持触控与电脑键盘；手机和平板直接点按屏幕琴键。
- 电脑键盘是辅助映射，不是真实钢琴的物理等价物：白键 `Z X C V B N M , . / N1–N6` 连续顺延，黑键 `A S · F G H · K L · ; ' Enter`。D、J 留空，小键盘 7–9 不参与黑键；屏幕琴键仍按真实钢琴几何排列。
- 屏幕琴键严格按真实钢琴几何排列；10 个黑键均落在正确白键缝隙之间。
- 48 节主课都必须包含国内或官方来源，且禁止混入 YouTube；运行时禁止 Web MIDI 接入。
- 离线测试使用独立临时目录，结束后自动停止服务并清理数据。

### 1.14 账户数据控制

- 账户弹窗可删除账户与云端进度，并在应用内二次确认。
- 删除后撤销所有会话、级联清除服务器进度；本机练习记录保留。
- 移动端账户入口直达计划设置，删除与同步流程共享同一套弹窗焦点管理。

### 1.13 accessibility

- Modal focus entry, focus trap, Escape close and focus restoration.
- Background shell inert while dialogs are open.
- Visible keyboard focus and larger touch targets.
- Selection semantics and regression tests for onboarding.

### 1.12 节奏钢琴

- 内置双八度虚拟电子琴，四首公共领域短曲各有独立节拍与落点。
- 手机、平板可横屏直接弹奏；电脑可用屏幕标注的两排辅助键位演奏。
- 节奏钢琴的双八度屏幕琴键按真实白键与黑键位置绘制；电脑键盘用两排辅助键位演奏。
- 10 音跟弹保留自己的低音区入门映射：白键 `Z X C V B N M`，黑键 `S D G H J`。
- 支持触控、键盘、暂停、全屏、准确率、连击、XP 和练习记录。
- 曲谱仅链接公共领域或官方来源，不内置受版权保护的曲谱。

### 1.11 自适应复习

- 未通过掌握检查、低评分练习或写了具体卡点的练习会自动加入复习队列。
- 每项复习按 1 / 3 / 7 / 14 / 30 天间隔推进；复习表现会决定下一次到期时间。
- 首页显示到期复习数量，学习记录页展示复习阶段并可直接开始 10 分钟定向复习。
- 复习数据会随账户同步，并包含在本地备份导入中。

### 1.10 跟弹练习

- 课程内和首页都可进入 10 音跟弹练习，提供示范播放、目标音高亮和即时对错反馈。
- 支持鼠标/触屏点击与电脑键盘辅助映射，不依赖外部设备。
- 按准确率结算 1–3 星与 5/10/15 XP，保存最佳准确率、最佳连对和练习历史。
- 跟弹成绩会进入每日目标、XP、四项能力报告与技术练习统计。
- 手机、平板和电脑都可直接使用触屏或键盘演奏。

### 1.9 掌握门槛与能力报告

- 每节课程的三题掌握检查会写入本地状态，并在完成页显示最好成绩。
- 普通课程至少达到 2/3 才计入完成并解锁下一课；未通过只保存为练习记录，不发课次 XP。
- 快练、曲目训练与弱点复习不经过该门槛。
- 学习记录新增读谱、技术、曲目、听觉四项能力与最弱项下一步建议。
- 首页收敛为单一路径：主课、短练、音乐游戏，减少并列入口。
- 使用本机中文字体栈，并在 Windows 上优先 Microsoft YaHei UI。

### 1.8 掌握检查

- 每节课程可打开三题掌握检查，覆盖动作、练习方法和具体技术。
- 检查结果会保存到本地状态，并显示在完成页。


### 1.7 曲目库

- 10 首 0–8 级曲目，覆盖入门、初级、中级与高级。
- 支持按难度筛选、按曲名或作曲家搜索。
- 每首曲目有五个训练阶段：分段认谱、分手慢练、慢速合手、流畅连接、完整演奏。
- 曲目训练为 25 分钟独立会话；完成一次推进一个阶段并获得 15 XP。
- 曲谱只链接公共领域或官方来源，不在项目内托管受版权保护的曲谱。

### 1.6 弱点复习

- 低评分或写下具体问题的练习会进入“今天该复习什么”。
- 复习会话为 10 分钟：定位问题、慢速重练、接回前后、记录新状态。
- 复习记录独立保存，不会伪造成整课完成。

### 1.5 定位与短练

- 五题定位测评，根据结果建议从第 1 / 3 / 5 / 7 / 9 周开始。
- 5 分钟快练：1 分钟热身、2 分钟技术、1 分钟视奏、1 分钟复盘。
- 快练记录计入练习历史与每日任务，不标记整课完成，避免课程进度失真。
- 静态在线体验版明确提示“本机保存”，不再展示不可用的登录表单。

### 1.4 账户与跨设备同步

- 可选账户：注册/登录/同步/退出/删除，游客模式无需账户；删除账户会清除云端进度并撤销会话。
- PBKDF2 密码哈希、HttpOnly SameSite Cookie、会话过期与登录限流。
- SQLite 服务端进度存储，支持版本冲突检测与手动/自动同步。
- 离线优先：本地先保存，恢复网络后补传；账户进度按版本合并。
- 安全边界：数据库不作为静态文件暴露，API 拒绝跨源写请求。

### 1.3 学习闭环

- 首次进入提供三步目标设置，创建后直接进入第一课。
- 课程按顺序解锁；完成一课自动进入下一课，不再跳回内容列表。
- 支持中途退出与刷新恢复上次步骤、剩余时间。
- 进度体系：XP、等级、每日三项任务。
- 小游戏升级为“看音名找键”与“听声音辨音”双模式，支持重听、连击与最佳成绩。
- 练习页增加可选节拍器（60/72/84/96 BPM）。
- 计划可重新选择目标、恢复默认或清除全部本地数据。

### 1.2 首页重构

- 单一“开始今日练习”主行动，减少并列入口。
- 首页直接显示本周四次练习与 12 周阶段轨迹。
- 新增音名找键小游戏，带连击、得分和最佳成绩。
- 字体改用本机常用中文字体优先，不加载远程字体。
- 移除来源筛选门槛说明、核验日期和无关资料标签。

## 快速开始

### 本地静态版

```bash
python -m http.server 8787
```

浏览器访问 `http://127.0.0.1:8787`。

Windows 双击 `启动PianoPath.cmd` 也会启动后端模式。

### 后端模式

```bash
python server.py
```

服务器默认监听 `http://127.0.0.1:8787`，数据写入 `data/state.json`。**无需安装第三方依赖。**

### 直接离线

`琴阶PianoPath.html` 为单文件版本，双击即可使用；进度保存在浏览器 `localStorage`。

修改源码后重新生成：

```bash
python tools/build-standalone.py
```

本机字体优先使用 `Microsoft YaHei UI`，其次 `PingFang SC`；不加载远程字体。

跟弹练习与节奏钢琴不依赖外部设备；手机、平板和电脑均可直接操作。

## 个性化 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 服务状态 |
| GET | `/api/plan/default` | 默认计划 |
| POST | `/api/plan` | 根据每周时长/天数/阶段/风格生成计划 |
| GET / POST | `/api/state` | 读取/保存学习状态 |
| GET | `/api/curriculum` | 完整课程与资源数据 |
| POST | `/api/auth/register` | 注册并建立会话 |
| POST | `/api/auth/login` | 登录并建立会话 |
| GET | `/api/auth/me` | 当前账户状态 |
| POST | `/api/auth/logout` | 退出并清除会话 |
| POST | `/api/auth/delete` | 删除账户并级联清除云端进度 |
| GET / POST | `/api/sync` | 跨设备读取/写入进度，带 revision 冲突检测 |

示例：

```bash
curl -X POST http://127.0.0.1:8787/api/plan \
  -H "Content-Type: application/json" \
  -d '{"daysPerWeek":4,"sessionMinutes":60,"level":"zero","style":"classical","goal":"半年内完整弹一首小奏鸣曲"}'
```
