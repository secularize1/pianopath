# Piano samples

These 26 MP3 samples are from the FluidR3_GM acoustic grand piano set, served by the MIDI.js Soundfonts project.

- Source: https://gleitz.github.io/midi-js-soundfonts/FluidR3_GM/acoustic_grand_piano-mp3/
- Project: https://github.com/gleitz/midi-js-soundfonts
- License: Creative Commons Attribution 3.0 (CC BY 3.0)
- License text: https://creativecommons.org/licenses/by/3.0/us/

PianoPath uses the samples locally so the virtual piano does not depend on runtime access to a third-party server. The samples are unmodified MP3 assets. If the browser cannot decode them, PianoPath falls back to its own multi-layer synthesized piano.
